## 1. Общее описание

Программа представляет собой CLI-инструмент для построения и визуализации графа зависимостей пакетов формата **Java (Maven)**.

Основные возможности:
- Загрузка параметров из конфигурационного файла формата **INI**
- Получение прямых зависимостей пакета указанной версии (без использования менеджеров пакетов и сторонних библиотек)
- Построение транзитивного графа зависимостей алгоритмом **DFS с рекурсией**
- Корректная обработка циклических зависимостей
- Поиск **обратных зависимостей** (пакеты, которые зависят от заданного)
- Формирование текстового представления графа на языке **Graphviz (DOT)**
- Опциональный вывод зависимостей в виде **ASCII-дерева**
- Режим тестирования на искусственном графе (пакеты — большие латинские буквы)

Готовые средства (менеджеры пакетов, библиотеки) для получения зависимостей **не используются**.

## 2. Описание всех функций и настроек

### 2.1. Параметры конфигурации (`config.ini`)

Файл должен содержать секцию `[settings]` со следующими параметрами:

| Параметр           | Тип    | Описание                                                                 | Пример                                      |
|--------------------|--------|--------------------------------------------------------------------------|---------------------------------------------|
| `package_name`     | строка | Имя анализируемого пакета. В реальном режиме — `groupId:artifactId`     | `org.springframework:spring-core` или `A`  |
| `repo_url`         | строка | URL Maven-репозитория **или** путь к файлу тестового репозитория        | `https://repo1.maven.org/maven2`            |
| `test_mode`        | bool   | Режим работы с тестовым репозиторием (`true` / `false`)                 | `true`                                      |
| `package_version`  | строка | Версия пакета                                                           | `5.3.21`                                    |
| `ascii_tree`       | bool   | Выводить зависимости в формате ASCII-дерева (`true` / `false`)          | `true`                                      |

### 2.2. Модули программы

| Модуль              | Назначение                                                                 |
|---------------------|----------------------------------------------------------------------------|
| `config_loader.py`  | Загрузка и валидация INI-конфигурации, обработка ошибок параметров        |
| `maven_parser.py`   | Скачивание POM-файла по HTTP и извлечение прямых зависимостей             |
| `graph_builder.py`  | Построение графа, рекурсивный DFS, обнаружение циклов, тестовый режим     |
| `reverse_deps.py`   | Поиск обратных зависимостей с использованием DFS                          |
| `visualizer.py`     | Генерация Graphviz DOT и ASCII-дерева                                     |
| `main.py`           | Точка входа, объединяет все этапы                                         |

### 2.3. Основные функции

- `load_config(path)` — загружает и проверяет все параметры из INI
- `get_direct_dependencies(name, version, repo_url)` — возвращает список прямых зависимостей
- `DependencyGraph.dfs(start)` — рекурсивный обход в глубину с обнаружением циклов
- `DependencyGraph.get_transitive_deps(package)` — транзитивные зависимости
- `find_reverse_dependencies(graph, target)` — пакеты, зависящие от target
- `to_graphviz(graph, root)` — текстовое представление на языке Graphviz
- `print_ascii_tree(graph, root)` — вывод ASCII-дерева

## 3. Команды для сборки проекта и запуска тестов

Проект написан на чистом Python 3 и не требует сторонних библиотек для основной работы (только стандартная библиотека).  
Для запуска тестов используется `pytest`.

### Установка зависимостей для тестов (опционально)

```bash
python -m pip install pytest
```

### Запуск приложения

```bash
make run
# или
python -m src.main
# или
./run.sh
```

### Запуск тестов

```bash
make test
# или
python -m pytest tests/ -v
```

### Очистка временных файлов

```bash
make clean
```

## 4. Примеры использования

### 4.1. Тестовый режим

Файл `config.ini` уже настроен на тестовый репозиторий:

```ini
[settings]
package_name = A
repo_url = tests/fixtures/test_repo.txt
test_mode = true
package_version = 1.0.0
ascii_tree = true
```

Запуск:

```bash
make run
```

Ожидаемый результат:
- Вывод всех параметров конфигурации
- Транзитивные зависимости пакета `A`
- Обнаружение цикла (через `E → B`)
- Обратные зависимости
- Graphviz DOT-описание
- ASCII-дерево 
### 4.2. Формат тестового файла репозитория

```
A -> B C
B -> D
C -> D E
D ->
E -> B
F -> A
```

Пакеты обозначаются большими латинскими буквами.  
Строка `PACKAGE -> DEP1 DEP2 ...` означает, что пакет зависит от перечисленных.
